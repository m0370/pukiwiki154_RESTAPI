# v2.2.1（2026-09-11）

導入手順と初期設定画面を改善した更新です。APIの既存キーと設定は引き続き使えます。

## 変更点

- Claude Codeはユーザースコープ（`--scope user`）を推奨。macOS / LinuxのBash、WindowsのPowerShellそれぞれの登録手順と、既存設定からの移行手順を記載しました。
- 登録時にサーバーの実際のパスを取得し、URLとキーを入力する手順に変更しました。例示用の `/path/to/...` を誤って登録する問題を避けます。
- ブラウザーでのキー発行とClaude Desktopの設定欄への入力を、READMEと同梱説明書に反映しました。
- API設定画面はPukiWiki標準の `skin/pukiwiki.css`（`SKIN_DIR`に追随）を使用します。独自スキンは、そのサイトに合わせて参照先を調整してください。
- 設置用ZIPにClaude Code用の `pukiwiki-mcp` フォルダと説明書を追加しました。MCPBは従来どおり同梱します。個人用のキー・設定・`run.sh` は含めません。
- REST API、Node MCP、MCPBのバージョン表記を2.2.1に揃えました。

ユーザースコープとキーの保管方法は別の設定です。macOS専用のキーチェーンは必須ではありません。配布物の更新だけでは、既存のClaude Code登録を自動移行しません。[移行手順](../pukiwiki-mcp/README.md#claude-code-user)に従ってください。別のPCには、そのPCで登録します。Androidは当面対象外です。

## 更新方法

既存の `config.local.php` と公開領域外のキー・履歴を保持し、[READMEの更新手順](../README.md#update)に従って更新してください。独自カスタマイズがあるサイトでは差分を確認してください。

Claude Desktopは新しいMCPBをインストールして設定を確認します。Claude Codeは登録先のNode版ファイルを更新します。どちらも既存キーを再発行する必要はありません。
