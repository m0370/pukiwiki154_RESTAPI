PukiWiki API 2.2.1 はじめに

PukiWiki 1.5.4 UTF-8版に、Claude Desktopからの検索・編集・バックアップ閲覧・添付ファイル管理を追加します。SSH・ターミナル・Node.jsの手動インストールは不要です。

用意するもの

PHP 8.1以上とHTTPSで動作するPukiWiki、FTPソフト、ブラウザー、デスクトップ拡張に対応するClaude Desktop（macOS／Windows）、PukiWikiの管理者パスワードを用意してください。PHPから書き込めるWeb非公開のフォルダが必要です。

1. FTPで配置する

このZIPに含まれる rest-api-v2 フォルダを、PukiWikiの index.php と同じ階層へアップロードします。ドットで始まる隠しファイルも含めてください。pukiwiki-mcp.mcpb はパソコンに残します。

2. ブラウザーで初期設定する

https://あなたのサイト/PukiWikiの設置場所/rest-api-v2/setup/index.php を開きます。PukiWikiの凍結・解除に使う管理者パスワードでログインしてください。

保存先の候補を検査して設定します。作成できない場合は、FTPで公開フォルダの外にフォルダを作成して、その絶対パスを指定してください。非公開の保存先を作れないホスティングは、今回のブラウザー設置方式に対応しません。

接続キーを発行します。ページを編集したい場合は編集権限、添付をアップロード・削除したい場合は添付の変更許可も選択してください。閲覧・編集認証があるサイトでは、実在するWikiユーザーを選びます。キーは発行直後に一度だけ表示されます。

3. Claude Desktopに追加する

pukiwiki-mcp.mcpb を開いてインストールします。開けない場合はClaude Desktopの設定で「拡張機能（Extensions）」を開き、詳細設定などにあるローカル拡張のインストールからこのファイルを選択します。表記はClaude Desktopのバージョンにより異なります。組織管理でローカル拡張が禁止されている場合は管理者による許可が必要です。

拡張の設定画面へAPI URLとAPIキーを貼り付けます。添付用フォルダも選択してください。初期値はダウンロードフォルダです。設定JSONを手で編集する必要はありません。

4. 接続を確認する

Claudeに「Wikiの接続状態を確認して」「FrontPageを読んで」と依頼します。接続できたら「肺癌とALKの両方を含むページを検索して」「このページの標準バックアップを見せて」などを試せます。

添付を送るときは、ファイルを添付用フォルダに置いて「このファイルを○○ページに添付して」と依頼してください。会話欄にドラッグしたファイルを拡張が直接取り出す機能はありません。

Claude Codeで使う場合（macOS / Windows / Linux）

同梱の pukiwiki-mcp フォルダをPC上に保存し、OS別の登録手順に従ってユーザースコープ（--scope user）で登録します。Node.js 18以上とClaude Codeが必要です。同じPC・同じOSユーザーのすべての作業フォルダで使えます。登録後はこのフォルダを移動・削除しないでください。Mac専用のキーチェーンやrun.shは不要です。これはClaude Desktopの拡張とは別の設定です。Androidは当面対象外です。

複数のPCで使う

ブラウザーの設定画面で、PCごとに名前の異なるキーを発行します。各PCの拡張設定またはClaude Codeに、それぞれのキーを登録してください。API URLは共通です。キーの発行・再発行だけではPC側の設定は更新されません。.envへの記載は不要です。

更新日時を変えずに編集する

Claudeに「更新日時を変えずに修正して」と依頼すると、notimestampを指定して保存できます。既存ページの更新日時と更新一覧の順序を維持し、本文・スナップショット・監査ログは更新します。通常は日時を更新します。

添付ファイルについて

一覧・取得・アップロード・削除に対応します。転送は1ファイル5 MiBまで（アップロードはPukiWiki側の上限がさらに小さければそちらに従います）。新規アップロードはPDF・画像・テキスト・Markdown・CSV・Office文書・ZIPが対象です。添付の上書きはしません。差し替えは削除してから同名でアップロードしてください。削除したファイルはPukiWikiの添付履歴に残り、再取得できます。改名と履歴の完全削除はWeb画面で行ってください。

既存の設置を更新するとき

まずFTPで既存の rest-api-v2 をパソコンへバックアップしてください。新しいフォルダを別名でアップロードしてから、既存の config.local.php を新しいフォルダへコピーします。FTPのフォルダ名変更で入れ替えます。切替中はAPIを使わず、完了後に接続を確認してください。失敗時は古いフォルダに戻せます。既存の非公開データとキーは削除しないでください。公開フォルダ内にデータを置く旧構成は、更新前に管理者向けREADMEを確認してください。

既存のキーは引き続き使えます。添付の変更権限は自動付与されないため、必要なら設定画面で新しいキーを発行してください。Claude Desktop側も新しい拡張へ更新します。

困ったとき

設定画面が404なら設置場所、500ならPHPのバージョンとFTP転送漏れ、401ならキー、403ならキーの権限とWikiユーザーを確認してください。API URLは設定画面に表示された index.php で終わるものを使用します。ブラウザーでキーを失効・再発行できます。
